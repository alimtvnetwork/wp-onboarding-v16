## 1. Format Overview

| Format | Trigger | Content |
|--------|---------|---------|
| **Full Report** | Copy → Copy Full Report | Markdown with all frontend + backend diagnostics |
| **Report + Backend Logs** | Copy → Copy with Backend Logs | Full Report + error.log.txt appended |
| **error.log.txt** | Copy → Copy error.log.txt | Raw backend error log file |
| **log.txt** | Copy → Copy log.txt | Raw backend full log file |
| **Full Bundle (ZIP)** | Download → Full Bundle | ZIP containing report.md + error.log.txt + log.txt |

### Copy Menu Structure

```
[▼ Copy]
├── Copy Full Report          → generateErrorReport() output
├── Copy with Backend Logs    → generateErrorReport() + error.log.txt
├── ─────────────────
├── Copy error.log.txt        → Raw error log from GET /api/v1/logs/error
└── Copy log.txt              → Raw full log from GET /api/v1/logs/full
```

### Download Menu Structure

```
[▼ Download]
├── Full Bundle (ZIP)         → POST /api/v1/errors/bundle
├── ─────────────────
├── error.log.txt             → GET /api/v1/logs/error
├── log.txt (Full)            → GET /api/v1/logs/full
├── ─────────────────
└── Report (.md)              → generateErrorReport() as .md file
```

### Generation Logic

```typescript
// In GlobalErrorModal.tsx → copyFullError()
let text = generateErrorReport(error, { appName, appVersion, gitCommit, buildTime });
try {
  const resp = await api.getBackendErrorLog();
  if (resp.success && resp.data?.content) {
    text += `\n### Backend error.log.txt\n\`\`\`\n${resp.data.content}\n\`\`\`\n`;
  }
} catch { /* skip */ }
navigator.clipboard.writeText(toClipboardText(text));
```

| `Go Backend Stack:` | File:line + function for each Go frame |

### Session ↔ Error Linkage

```
Error Modal opens
  │
  ├─ CapturedError.sessionId present?
  │     │
  │     ├─ YES → Auto-fetch GET /api/v1/request-sessions/{id}
  │     │         → Merge into Session tab (logs, request, response, stack trace)
  │     │         → Parse responseBody for DelegatedRequestServer
  │     │
  │     └─ NO → Session tab shows "No session data available"
  │
  └─ CapturedError.envelopeErrors.DelegatedRequestServer present?
        │
        ├─ YES → Show in Stack tab (delegated server section)
        │         → Show in Request tab (3-hop chain: React → Go → Delegated)
        │         → Show in Traversal tab
        │
        └─ NO → Standard 2-hop display (React → Go)
```

## 9. Generator Code Reference

### Source File

`src/components/errors/errorReportGenerator.ts`

This is a **pure function** with no React dependencies — fully portable to any TypeScript project.

### Function Signature

```typescript
function generateErrorReport(
  error: CapturedError,
  app?: {
    appName: string;
    appVersion: string;
    gitCommit?: string;
    buildTime?: string;
  }

```

### Dependencies

| Import | Purpose |

### Replication Guide

To replicate this error reporting system in another project:

1. **Copy `errorReportGenerator.ts`** — Pure function, no side effects
2. **Implement `CapturedError` interface** — See Section 2 of `spec/error-modal/README.md`
3. **Implement `errorStore`** — Zustand store with `captureError()`, `buildCapturedError()`
4. **Implement `parseEnvelope()`** — Extract `Errors`, `MethodsStack`, `Attributes` from API responses
5. **Implement click path tracking** — DOM click listener that records interactive element clicks
6. **Implement execution logger** — Optional debug-mode call chain tracker
7. **Wire Copy/Download menus** — Use the menu structures documented in Section 1
