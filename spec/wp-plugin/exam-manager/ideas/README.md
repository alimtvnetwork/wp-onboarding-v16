# Ideas Folder

This folder contains feature proposals and improvement ideas for the Exam Manager plugin.

## Naming Convention

All idea files must follow this pattern:

```
{nn}-{idea-title}.md
```

- `{nn}` — Two-digit sequence number (01, 02, 03...)
- `{idea-title}` — Lowercase, hyphen-separated title

### Examples

- `01-gamification-badges.md`
- `02-ai-question-generator.md`
- `03-mobile-app-integration.md`

## File Template

Each idea file should include:

```markdown
# Idea: {Title}

**Status:** Draft | Under Review | Approved | Rejected | Implemented  
**Priority:** Low | Medium | High | Critical  
**Complexity:** Simple | Moderate | Complex  
**Created:** YYYY-MM-DD  

## Summary

One-paragraph description of the idea.

## Problem Statement

What problem does this solve? Why is it needed?

## Proposed Solution

High-level description of the solution.

## Acceptance Criteria

- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

## Technical Considerations

- Dependencies
- Database changes required
- API changes required
- Security implications

## Related Specs

- [Link to relevant spec file](../01-admin-backend/split-spec/nn-filename.md)

## Notes

Additional context, links, or references.
```

## Workflow

1. Create new idea file with next available sequence number
2. Fill in the template sections
3. Set status to `Draft`
4. Review and update status as idea progresses
5. When implemented, update status and link to actual spec files
