# 23. Responsive Design

## Overview
Mobile, tablet, and desktop layout adaptations.

---

## 23.1 Breakpoints

| Device | Width | Layout |
|--------|-------|--------|
| Mobile | < 640px | Single column, stacked |
| Tablet | 640-1024px | Two columns where applicable |
| Desktop | > 1024px | Multi-column, sidebars |

---

## 23.2 Mobile Adaptations

- Full-width cards
- Hamburger menu navigation
- Touch-friendly buttons (48px min)
- Stacked form inputs

---

## 23.3 Acceptance Criteria

- [ ] Mobile layout works correctly
- [ ] Tablet adapts properly
- [ ] Desktop uses full width
- [ ] Touch targets 48px minimum
