# 24. Tech Stack

## Overview
Recommended frontend technologies and dependencies.

---

## 24.1 Core Technologies

- **HTML5**: Semantic markup
- **CSS3**: Flexbox/Grid, media queries
- **JavaScript**: Vanilla or minimal framework

---

## 24.2 Libraries

| Purpose | Library |
|---------|---------|
| Markdown | `marked.js` or `markdown-it` |
| Syntax Highlighting | `highlight.js` |
| HTTP Client | Native `fetch` API |
| Video Embeds | YouTube/Vimeo iframe API |

---

## 24.3 Optional Framework

- Vue.js or Svelte for SPA behavior
- React if preferred
