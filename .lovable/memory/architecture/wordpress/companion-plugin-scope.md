# Memory: architecture/wordpress/companion-plugin-scope
Updated: 2026-02-14

The companion plugin `plugins-onboard` is explicitly out of scope for all code improvements, migrations, and refactoring. Do not modify, audit, or suggest changes to any files under `wp-plugins/plugins-onboard/`. All coding standards, enum migrations, and naming conventions apply only to the main `riseup-asia-uploader` plugin.
