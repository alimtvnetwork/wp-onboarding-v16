# Memory: architecture/coding-standards/control-flow-and-formatting
Updated: 2026-02-21

Code style across all languages (PHP, TypeScript, Go) is governed by a canonical spec at `spec/01-coding-guidelines/code-style.md` (v3.1.0) with ten rules: (1) mandatory curly braces `{}` for all control structures, (2) no nested `if` blocks — flatten via combined conditions or early returns, (3) extract any `if` condition with 2+ operators into a named boolean variable, method, or constant, (4) blank line before `return` or `throw` unless it's the sole statement in its block, (5) blank line after `}` when more code follows (exception: consecutive `}` or `else`/`catch`), (6) max 15 lines per function body, (7) reinforced zero-tolerance nested-if ban, (8) no leading backslash on global types, (9) multi-line params when >2 parameters, (10) **blank line before control structures (`if`/`for`/`foreach`/`while`) when preceded by one or more non-brace statements** — separates setup from decision logic; exception: no blank line needed when the control structure is the first statement in a block or immediately follows a closing `}`. Functions with more than 2 parameters must use multi-line signatures with one parameter per line and a trailing comma (where syntax permits).
