# Memory: spec-management/project-overview

**Spec Management Software** is a local-first specification authoring and validation system. Backend: Golang + SQLite (GORM). Frontend: React via Lovable. Key features: specification authoring with Markdown templates, AI-powered drafting and validation, Git integration, consistency checking with health scores (target 100/100), and code generation from specs. CLI tools: `gsearch` (search), `brun` (build runner). Architecture: local-first with hybrid storage (SQLite for metadata, filesystem for content), dual-format artifacts (Markdown + JSON), iterative quality loops (auto-fix until 99%+ target). AI integration includes voice-to-text, RAG context retrieval, and three-phase code generation pipeline (Writing → Consistency → Build Verification).
